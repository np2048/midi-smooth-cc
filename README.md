# MIDI Smooth CC

Real-time LV2 MIDI plugin for smoothing noisy or quantized MIDI Control Change
values, primarily targeted at Electronic Wind Instruments (EWI), breath
controllers, and other continuous MIDI controllers driven by analog sensors.

## Current status

In development:

- No tests
- No working prototype
